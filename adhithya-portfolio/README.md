# Adhithya S U — Creative Developer Portfolio

A responsive, warm-editorial portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and semantic structure
- `style.css` — design system, responsive layouts, and motion
- `script.js` — mobile menu, theme switch, reveal effects, cursor, footer year
- `assets/profile.jpg` — add your own portrait here
- `assets/resume.pdf` — add your final resume here when ready

## Run locally
1. Open this folder in Visual Studio Code.
2. Install the **Live Server** extension if needed.
3. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in a browser; Live Server is recommended for development.

## Personalize before publishing
1. Add your photo at `assets/profile.jpg` (JPG is easiest; keep the filename exact).
2. Replace the project links in `index.html` with each project's direct GitHub repository URL.
3. Add your resume as `assets/resume.pdf` and add a download link in the contact or hero area when ready.
4. Check the project descriptions and achievement wording for accuracy.
5. Test the site at mobile and desktop sizes before deploying.

## Notes
- Google Fonts require an internet connection; system fallback fonts are included.
- The theme toggle remembers the selected theme in the current browser when storage is available.
- Custom cursor effects are desktop-only and respect reduced-motion preferences.
- The current project links point to the GitHub profile until direct repository URLs are supplied.
